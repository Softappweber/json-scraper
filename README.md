# 🚀 Contact Scraper Pro

Complete Website Contact Scraper with Tor Integration and Web Interface

## ✨ Features
- CLI Scraper
- Web Interface (Browser)
- Tor Integration (Anonymous)
- Email Extraction
- Phone Extraction
- CSV/Excel Export
- Deduplication
- Proxy Support

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run scraper
python run.py
```

## 📝 Usage

### CLI Mode
1. Select option 1
2. Enter URLs
3. Find results in `output/` folder

### Web Mode
1. Select option 2
2. Open http://localhost:8000
3. Paste URLs in browser

### Tor Mode
1. Select option 3
2. Ensure Tor is installed
3. Scrape anonymously

## 📊 Output
- CSV file
- Excel file
- Both saved in `output/` folder
